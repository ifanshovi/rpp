Petunjuk Penggunaan

Aplikasi ini mempermudah pembuatan RPP Kurikulum Berbasis Cinta (KBC).

Cara Menggunakan:

  1. Isi form Identitas Guru dan Sekolah.
  2. Pilih Model Pembelajaran, Panca Cinta, dan Integrasi Ekoteologi (dimensi, tema, dan opsi dalil). Bagian lain bersifat opsional.
  3. Gunakan isian Keterangan Lain jika ingin memberi perintah/petunjuk khusus kepada AI.
  4. Pilih metode pembuatan:
    • Buat Pratinjau Kosong: Membuat kerangka kosong di halaman Pratinjau untuk diketik secara manual.
    • Buat Pakai Gemini: Memunculkan Prompt untuk Anda copy dan paste ke AI, lalu masukkan hasilnya kembali ke aplikasi.
  5. Klik Cetak (PDF) untuk menyimpan sebagai PDF dengan format file otomatis: RPP_Nama Penyusun_Mapel_Kelas_Materi.
